# 도시 채팅

Project Moon의 「도시」를 무대로 한 AI 롤플레이 채팅게임입니다. 림버스 컴퍼니의 수감자, 도서관의 사서들과 이야기를 나눌 수 있습니다. 구조는 「키보토스 채팅」의 설계를 따릅니다.

- 플레이: GitHub Pages 루트(`index.html`). ⚙ AI 설정에 본인 API 키(Claude · Gemini · OpenAI 호환)를 넣고 시작합니다.
- 예전 카드 서바이벌 게임은 [`legacy/`](legacy/)에 그대로 남아 있습니다.

## 모드와 기능

| 기능 | 내용 |
|---|---|
| 자유 모드 | 장소를 고르면 그곳에 있을 법한 인물이 등장합니다. 만난 인물 모두에게 호감도가 쌓입니다. |
| 1:1 대화 | 한 사람과 대화합니다. 장소·시간·차림·상황을 정할 수 있습니다. |
| 스토리 모드 | 시나리오 11종과 자유 시나리오를 고를 수 있고, 최대 6명이 함께 등장합니다. |
| 호감도·기억 | 인물별 호감도(0~100)를 링으로 보여 줍니다. 안 요약된 메시지가 30개를 넘으면 오래된 부분을 자동으로 요약하고, 최근 12개는 원문 그대로 둡니다. |
| 감정 말풍선 | 대사마다 ♪ 💦 💢 같은 감정 기호가 아이콘 위에 붙습니다. |
| 메시지 편집 | 편집, 삭제, 다시 생성, 여기까지 되돌리기, ⏩ 이어서. 지우면 그 답장이 바꾼 호감도와 장면도 함께 되돌아갑니다. |
| 입력 도우미 | `" "` 버튼은 대사, `* *` 버튼은 행동을 넣습니다. |
| 안정성 | 스트리밍으로 받습니다. 사용 한도에 걸리거나 30초 동안 응답이 없으면 다른 모델로 자동 전환합니다. |
| 화면 | 다크·라이트·시스템 테마를 지원하고 모바일 배치를 갖췄습니다. |

## 구조

| 경로 | 역할 |
|---|---|
| `data/world.json` | 세계관 요약, 규칙, 세계관 문서(키워드로 골라 넣음), 차림, 시간대, 자유 모드 장소 |
| `data/factions.json` | 세력(림버스 컴퍼니 LCB · 도서관)의 이름·색·설명 |
| `data/scenarios.json` | 스토리 시나리오, 주인공 신분, 첫 장면 대사(직접 창작) |
| `tools/personas/*.json` | 인물별 성격(p), 말투(s), 태도(t), 관계(r), 높임(h), 주인공 호칭(c), 추정 표시(inferred) |
| `tools/build_roster.py` | 페르소나를 검증해 `data/characters.json`으로 합칩니다. 시나리오 오프닝이 높임·호칭과 맞는지도 점검합니다. |
| `tools/build_artifact.py` | `artifact/template.html`과 data를 합쳐 `index.html`을 만듭니다. |
| `artifact/template.html` | 화면, 프롬프트 조립, AI 호출, 후처리 |

빌드:

```bash
python tools/build_roster.py && python tools/build_artifact.py
```

`artifact/template.html`을 로컬 서버에서 직접 열면 `data/`를 불러와 빌드 없이 확인할 수 있습니다.

## 한 턴의 흐름

1. 입력을 `*행동*`과 `"말"`으로 나눠 `[주인공의 행동]` / `[주인공의 말]` 이름표를 붙입니다. 표시가 없는 글은 「~다.」로 끝나면 행동으로, 아니면 말로 봅니다.
2. 시스템 프롬프트를 이 순서로 조립합니다: 규칙 → 세계관 → 관련 문서 → 관련 세력 → 장면 인물 상세 프로필(최대 10명) → 모드 안내 → 주인공 → 요약 → 현재 장면.
3. 마지막 메시지 끝에 장면 인물 메모(높임·호칭·말투·관계)를 매 턴 다시 붙입니다.
4. 응답을 스트리밍으로 받습니다.
5. 숨은 태그 `[호감도 id:+n]`와 `[장면 장소|시간|등장 id,…]`를 떼어 내 호감도와 장면을 갱신합니다.
6. 후처리로 영어 이름·id를 한국어 이름으로 바꿉니다. 존댓말 인물이 주인공을 「너」나 「이름+아/야」로 부르면 그 인물의 호칭으로 고칩니다. 대사 줄 안에서만 고치고 다른 낱말은 건드리지 않습니다.
7. 요약이 필요하면 요약합니다.

## 미리 넣어 둔 문제 해결책

- **말투 붕괴**: 어미까지 풀어 쓴 말투 규칙과 「친해져도 말투는 안 바뀜」을 명시합니다. 호감도 설명에도 「말투와 높임은 바뀌지 않음」을 붙입니다.
- **호칭 변형**: 인물별 호칭 필드, 금지 규칙, 후처리 교정으로 막습니다.
- **영어 이름**: 「대사 이름은 한국어만」 규칙을 두고 후처리로 치환합니다.
- **행동·말 혼동**: 입력을 나눠 보내고 「행동은 이미 일어난 일」 규칙을 둡니다.
- **성격 뒤바뀜**: 최근에 실제로 말한 인물의 프로필을 늘 포함하고, 매 턴 메모를 다시 붙입니다.
- **예전 대화방에 새 설정이 안 먹힘**: 대화방마다 설정 지문을 저장합니다. 설정이 바뀌면 20턴 동안 「옛 말투 무시」 안내를 붙입니다.
- **아끼는 사람 비난**: 관계에 「누구를 어떻게 대하는지」까지 적고, 비난 금지 규칙을 둡니다.
- **잘못된 오프닝**: `build_roster.py`가 오프닝 대사의 높임·호칭을 검사합니다.
- **무한 로딩**: 30초 시간 초과와 모델 자동 전환으로 막습니다.

## 캐릭터 자료에 대해

페르소나는 한국어판 게임 스토리의 인상을 바탕으로 요약했습니다. 원작 대사는 옮기지 않았습니다. 공식 데이터 덤프로 전수 검토한 것은 **아닙니다**. 확인하지 못한 부분, 특히 처음 보는 주인공을 부르는 호칭은 각 페르소나의 `inferred`에 「추정」으로 표시했습니다. 게임 안에서도 인물 프로필을 열면 보입니다. 틀린 곳은 `tools/personas/*.json`을 고친 뒤 다시 빌드하면 됩니다. 이미 있는 대화방은 설정 변경을 자동으로 감지합니다.

## 보안

- API 키는 브라우저 localStorage(`pmc_ai_cfg`)에만 저장되고, 고른 AI 서비스 외에는 어디로도 보내지 않습니다.
- 대화 내보내기 파일에는 키가 들어가지 않습니다. 저장소에도 키를 커밋하지 않습니다(`.env`, `*.db`는 `.gitignore`).
- 저장소에는 저작권 이미지나 원문 대사를 넣지 않습니다. 아이콘은 이름 머리글자와 색으로만 표시합니다.
